# Caso Carolina Cobrizo — corrección de color cobrizo

## Resumen del caso

Carolina llegó al salón buscando un color cobrizo que no le habían podido lograr antes. Venía con antecedentes de tintura negra y tintura roja, dos pigmentos difíciles de retirar, por lo que se realizó un barrido de color y un trabajo técnico prolongado de masaje para emparejar la base. Después se llevó el cabello a un cobrizo uniforme, luminoso y parejo. El resultado fue una clienta feliz y satisfecha con un tono cobrizo espectacular.

## Control de metadatos y geolocalización

Antes del renombrado había 16 archivos: 9 fotos y 7 videos. Se mantuvieron las extensiones originales y se generó un manifiesto de control en `metadata-manifest-carolina-cobrizo.json`.

- Las 9 fotos tienen título, descripción, autor, copyright, palabras clave y ubicación del caso.
- Los 8 JPEG tienen GPS EXIF embebido con coordenadas `-53.13529, -70.94159`.
- El PNG tiene metadatos textuales internos con título, descripción, palabras clave, ubicación, `GPSLatitude` y `GPSLongitude`. macOS no expone esos campos como `kMDItemLatitude` / `kMDItemLongitude`, pero quedan dentro del archivo.
- La coordenada usada se tomó de las fotos del salón que ya venían geolocalizadas y eran consistentes entre sí.
- El proyecto web también contiene un mapa antiguo con coordenadas `-53.15, -70.923`; no se usó ese punto porque no coincide con los metadatos originales de los medios del caso.

Los videos fueron renombrados para SEO, pero no se reescribieron sus metadatos QuickTime porque no había `exiftool` instalado en el entorno. Si se necesita, el siguiente paso recomendado es agregar metadata QuickTime con ExifTool antes de subirlos.
